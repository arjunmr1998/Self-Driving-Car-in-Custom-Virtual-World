# 🚗 Self-Driving Car Simulation in Vanilla JavaScript

> A complete autonomous driving simulation built from scratch using **HTML5 Canvas** and **Vanilla JavaScript** — no TensorFlow, no game engine, no physics libraries.

This project extends my custom **Virtual World Editor** into a complete self-driving car simulator. Instead of relying on existing machine learning or simulation frameworks, every major component—vehicle physics, ray-casting sensors, neural networks, genetic evolution, collision detection, and visualization—was implemented from first principles.

The simulation trains **100 AI cars simultaneously**, continuously evolves their neural networks, and visualizes how the best-performing car learns to navigate through a procedurally generated city.

# How the Simulation Works

Every frame follows the same pipeline.

```text
Load World
     │
Spawn Cars
     │
Read Sensors
     │
Neural Network
     │
Generate Controls
     │
Move Car
     │
Detect Collisions
     │
Select Best Car
     │
Render Everything
```

This loop runs continuously at approximately **60 FPS**.

# Step-by-Step Execution

## Step 1 – Load the World

The simulation loads the city generated by my Virtual World Editor.

The world already contains:

- Roads
- Lane guides
- Buildings
- Trees
- Traffic lights
- Road markings

Instead of generating a new environment every run, the AI trains inside a persistent world.

## Step 2 – Spawn Vehicles

The simulation creates:

- **100 AI-controlled cars**
- Multiple traffic vehicles

Each AI car receives its own neural network.

Initially, almost every car crashes.

Over time, better networks survive.

## Step 3 – Ray-Casting Sensors

Every car continuously casts rays into the environment.

Example:

```text
        /
       /
Car --->
       \
        \
```

Each ray measures the nearest obstacle.

The sensors detect:

- Road borders
- Traffic
- Walls
- Nearby vehicles

The sensor readings become the neural network inputs.

# How the Sensors Work

The sensor system uses **ray casting**.

For each ray:

1. Compute its direction.
2. Extend it into the world.
3. Check intersections.
4. Return the nearest hit.

Mathematically,

```math
P = P_0 + td
```

where

- `P₀` = sensor origin
- `d` = normalized direction
- `t` = distance

The shortest detected distance becomes the sensor output.

This is conceptually similar to:

- LiDAR
- Laser scanners
- Depth sensing

# Neural Network

The neural network is implemented entirely from scratch.

No TensorFlow.

No PyTorch.

No external ML libraries.

Architecture:

```text
Sensors
   │
   ▼
Input Layer
   │
   ▼
Hidden Layer
   │
   ▼
Output Layer
```

The four outputs control:

- ⬆ Forward
- ⬅ Left
- ➡ Right
- ⬇ Reverse

Each frame:

```text
Sensor Values

↓

Feed Forward

↓

Control Signals

↓

Car Movement
```

---

# Feedforward Mathematics

Every neuron computes

```math
z = Wx+b
```

where

- `W` = weights
- `x` = inputs
- `b` = bias

The implementation stores:

- weights
- biases
- outputs

for every network layer.

The network learns by modifying these parameters.

---

# Genetic Algorithm

Instead of using gradient descent or backpropagation, the cars learn through evolution.

Workflow:

```text
Generate 100 Cars

↓

Drive

↓

Measure Performance

↓

Keep Best Brain

↓

Mutate Copies

↓

Repeat
```

This is inspired by biological evolution.

Each generation creates slightly different neural networks.

Eventually one network discovers successful driving behavior.

---

# Mutation

The mutation process slightly changes:

- weights
- biases

Instead of replacing values randomly, interpolation is used.

Conceptually:

```math
new = lerp(old,random,amount)
```

This keeps improvements while still exploring new behaviors.

↓

Velocity

---

# Collision Detection

Every car is represented as a polygon.

Instead of checking rectangles, polygon intersections are used.

Workflow:

```text
Car Polygon

↓

Road Border

↓

Edge Intersections

↓

Collision
```

This makes collisions much more accurate.

# Best Car Selection

The simulation continuously identifies the best-performing vehicle.

Selection is based on progress through the world.

The best car:

- remains highlighted
- has its neural network displayed
- becomes the parent of the next generation

Its brain can also be saved.

# Mathematical Concepts Used

This project combines several important concepts used in robotics and autonomous driving.

## Ray Casting

Each sensor follows

```math
P=P_0+td
```

Used in:

- LiDAR
- Laser scanners

---

## Feedforward Neural Networks

Every neuron computes

```math
z=Wx+b
```

followed by activation.

---

## Linear Interpolation

Mutation uses

```math
L(a,b,t)=a+t(b-a)
```

to smoothly evolve networks.

---

## Polygon Intersection

Collision detection checks whether any edges intersect.

This is much more accurate than bounding boxes.

---

## Coordinate Transformations

Vehicle movement continuously updates:

- position
- heading
- rotation

This mirrors the coordinate transformations used in robotics.
